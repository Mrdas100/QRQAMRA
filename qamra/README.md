# دوام شاهي قمرا
PWA للحضور والانصراف والبريك — العربية / বাংলা — بدون أي ذكاء اصطناعي.
**الواجهة:** GitHub Pages (مجلد `web/`) · **الخلفية:** Supabase (PostgreSQL + دالة Push واحدة).
كل المنطق (وقت السيرفر Asia/Riyadh، التأخير، البريك، الصلاحيات، حد المحاولات) داخل قاعدة البيانات.

## النشر (مرة واحدة، ~20 دقيقة)

**1) Supabase** — أنشئ مشروعًا مجانيًا على supabase.com، ثم من *SQL Editor* شغّل محتوى `supabase/migrations/001_schema.sql`.

**2) حساب المدير** — في SQL Editor:
```sql
select create_admin('owner', 'كلمة-مرور-قوية-8-أحرف-أو-أكثر');
```

**3) مفاتيح التنبيهات (VAPID)** على جهازك:
```
npx web-push generate-vapid-keys
```

**4) دالة التنبيهات** (Supabase CLI):
```
supabase login && supabase link --project-ref REF
supabase secrets set VAPID_PUBLIC_KEY=... VAPID_PRIVATE_KEY=... VAPID_SUBJECT=mailto:you@example.com CRON_SECRET=أي-نص-سري-طويل
supabase functions deploy notify --no-verify-jwt --project-ref REF
```
ثم شغّل `supabase/migrations/002_cron.sql` في SQL Editor بعد استبدال `REF` و`SECRET` (نفس CRON_SECRET). يفحص كل دقيقة ويرسل تنبيهات (قبل النهاية بـ 10 و5 دقائق، ثم عند النهاية، ثم كل 10 دقائق تجاوز).

**5) الإعدادات** — عدّل `web/config.js`: `SUPABASE_URL` و`ANON_KEY` (المفتاح العام publishable/anon فقط، **ليس** service_role) و`VAPID_PUBLIC_KEY`.

**6) GitHub Pages** — ارفع المشروع على GitHub (فرع `main`)، ثم *Settings → Pages → Source: GitHub Actions*. الرابط يظهر بعد أول تشغيل. لوحة المدير: `الرابط/admin.html`.

## أول استخدام
1. ادخل لوحة المدير ← **الإعدادات**: أضف الشفت (مثلًا 4:00 PM – 2:00 AM، بريك 40)، وحدد موقع المحل ونطاقه.
2. **الموظفون** ← أضف الموظفين (رقم، اسم عربي/بنغالي، PIN، شفت، يوم الإجازة).
3. أعطِ كل موظف الرابط ورقمه وPIN.

## ملاحظات مهمة
- **الآيفون:** يجب أن يثبّت العامل التطبيق (مشاركة ← إضافة إلى الشاشة الرئيسية) ويسجّل الدخول **من الأيقونة**. تخزين Safari منفصل عن التطبيق المثبّت، فلو سجّل من Safari ثم ثبّت سيُرفض جهازه ← استخدم «فك ربط الجهاز». التنبيهات على iOS تتطلب iOS 16.4+ وتطبيقًا مثبّتًا.
- **ربط الجهاز** يعتمد على معرّف عشوائي محفوظ في المتصفح؛ يمنع الاستخدام العادي من جوال آخر، لكنه ليس حماية مطلقة ضد شخص تقني.
- **GPS** للتسجيل والتحقق فقط: خارج النطاق يظهر تنبيهًا للمدير ولا يمنع التسجيل.
- **ساعات العمل** = مدة الدوام − مدة البريك. **المسموح** = مدة البريك الرسمية لكل بريك مأخوذ. البريك مرة واحدة للدوام (يمكن تغييره من الإعدادات).
- **PDF:** زر «تحميل PDF / طباعة» يفتح الطباعة ← اختر «حفظ كـ PDF» (يدعم العربية بلا مكتبات).
- التعديل الإداري على الأوقات: «الموظفون ← السجل ← تعديل إداري»، ويُسجَّل في سجل التدقيق (القديم/الجديد/من/متى).
- نسيان الانصراف: يُغلق الدوام تلقائيًا بعد 16 ساعة ويُعلَّم «أُغلق تلقائيًا» ليراجعه المدير.
- بعد كل نشر جديد غيّر `V` في `web/sw.js` ليتحدث الكاش فورًا.

## الاختبار
`tests/scenario.sql` يشغّل سيناريو الطلب كاملًا على PostgreSQL: دخول 4:05 م ← تأخير 5، بريك 8:00 م، تنبيهات 8:30/8:35/8:40، عودة 9:10 ← 70 د / مسموح 40 / تجاوز 30، انصراف 2:00 ص، ثم لوحة المدير والتقرير الشهري.
